Класс TextStorage задает контракт: метод save(self, text: str) -> None должен сохранять текст без ошибок
Подкласс ReadOnlyStorage наследуется от TextStorage, но при вызове save() выбрасывает исключение PermissionError('Это хранилище только для чтения'
В результате объект ReadOnlyStorage не может безболезненно заменить TextStorage в клиентском коде Editor при нажатии кнопки сохранить в Editor(ReadOnlyStorage()) программа падает с необработанным исклюением вместо ожидаемого поведения
