# oop-tasks

Репозиторий для сдачи задач по ООП. Каждый ученик работает **в своей ветке** — не в `main`.

Ниже — пошаговая инструкция: как настроить git, создать свою ветку, выложить её на GitHub и потом коммитить/пушить в неё изменения. Все команды выполняются в **терминале** (консоли).

---

## 0. Разовая настройка (делается один раз на компьютере)

Проверь, что git установлен:

```bash
git --version
```

Если команды нет — установи [Git](https://git-scm.com/downloads).

Представься git'у своим именем и почтой (эти данные попадут в коммиты):

```bash
git config --global user.name "Твоё Имя"
git config --global user.email "твоя@почта.com"
```

## 1. Склонировать репозиторий

Скачай проект к себе на компьютер (делается один раз):

```bash
git clone https://github.com/daniil-uni/oop-tasks.git
cd oop-tasks
```

Теперь ты внутри папки проекта. Все следующие команды выполняй здесь.

## 2. Создать свою ветку

Перед созданием ветки убедись, что ты на актуальном `main`:

```bash
git checkout main
git pull
```

Создай свою ветку и сразу переключись на неё. **Назови её своим именем/фамилией**, например `ivanov-ivan`:

```bash
git checkout -b ivanov-ivan
```

> `-b` означает «создать новую ветку». Без `-b` команда просто переключается на уже существующую.

Проверить, на какой ты ветке сейчас:

```bash
git branch
```

Звёздочка `*` стоит рядом с текущей веткой.

## 3. Выложить (запушить) ветку на GitHub

Свежесозданная ветка живёт только у тебя на компьютере. Чтобы она появилась на GitHub, выложи её:

```bash
git push -u origin ivanov-ivan
```

> `-u origin ivanov-ivan` — привязывает твою локальную ветку к ветке на GitHub. Это нужно сделать **только один раз**. Дальше можно пушить просто `git push`.

Теперь твоя ветка видна на GitHub в списке веток.

## 4. Работа: коммит и пуш изменений

Дальше цикл повторяется каждый раз, когда ты что-то сделал.

**1) Написал/изменил код** — сохрани файлы в редакторе.

**2) Посмотри, что изменилось:**

```bash
git status
```

**3) Добавь изменения в коммит.** Всё сразу:

```bash
git add .
```

или конкретный файл:

```bash
git add task1.py
```

**4) Зафиксируй коммит с понятным описанием того, что сделал:**

```bash
git commit -m "Решил задачу 1: сортировка массива"
```

**5) Отправь коммиты на GitHub:**

```bash
git push
```

Готово — твои изменения на GitHub, в твоей ветке. 🎉

---

## Шпаргалка (каждый день)

```bash
git status                       # что изменилось
git add .                        # добавить все изменения
git commit -m "что я сделал"     # зафиксировать
git push                         # выложить на GitHub
```

## Частые вопросы

**Я случайно оказался на `main`, как вернуться на свою ветку?**

```bash
git checkout ivanov-ivan
```

**Как узнать, на какой я ветке?**

```bash
git branch
```

**`git push` ругается `has no upstream branch`** — значит ты ещё не привязал ветку (шаг 3):

```bash
git push -u origin имя-твоей-ветки
```

**Хочу забрать свежие изменения из `main` к себе в ветку:**

```bash
git checkout main
git pull
git checkout имя-твоей-ветки
git merge main
```

---

⚠️ **Важно:** работай только в своей ветке. Не коммить и не пушь напрямую в `main` — туда изменения попадают только через проверку преподавателем.
